# 日记流

把指定日记文件夹作为数据源，在 Obsidian 中按天浏览、搜索和记录日记。作者：goo。

这是个人测试版，通过 BRAT 安装和更新。尚未提交 Obsidian 社区插件目录。

## BRAT 安装

1. 在 Obsidian 中安装并启用 BRAT。
2. 打开 BRAT 设置，选择 **Add beta plugin**。
3. 输入仓库地址：`https://github.com/OPENSB/obsidian-diary-stream`。
4. 选择版本 **0.2.0**，然后添加并启用插件。

如果库中已有手动安装的“日记流”，它与本仓库使用相同插件 ID `diary-stream`。BRAT 更新的是同一个插件；无需卸载或删除插件设置。

## 0.2.0 修改

0.2.0 面向手机端语音转文字记录与长段回读场景，重构为「柔雾软卡」界面与交互。通过 BRAT 升级时请选择 **0.2.0**（旧的 0.1.4 / 0.1.5 安装包保留，不覆盖）。

- 极简顶栏仅保留月份/年份入口（点击展开日历与热力图抽屉）以及搜索、筛选轻图标；桌面端保留双栏布局。
- 手机端新增避让 Obsidian 原生底部导航栏的右下角悬浮圆笔按钮，点击从按钮原位展开写作稿纸，支持抽屉手柄下拉关闭、软键盘高度适配与 SwiftUI 风格弹簧动效（同时尊重减少动态效果设置）。
- 写作支持光标处无代码行内插图（保存时原位写入标准 `![[...]]`）；长日记折叠态下隐藏正文内原位图并在正文下方展示紧凑缩略图带（可点开灯箱），点击右下角紧凑「展开」平滑舒展后图片回到文字原位。
- 补记双入口：写作稿纸顶部时间胶囊可展开快捷补记面板（现在 / 昨天 / 前天 / 自定义时间 + 标记为补记），历史日期章节头也提供 `+ 补记` 直达入口。
- 插件设置新增「外观色调」6 选 1（跟随 Obsidian 主题色 / 极简曜石黑 / 晴空钴蓝 / 晨雾抹茶 / 丁香暮紫 / 暖杏陶橙），浅色/深色模式即时生效。
- 保留凌晨 4 点分日、完整日期、旧格式兼容、原文件排序、冲突保护与未保存编辑确认。

本地语法检查与 23 项自动测试通过；尚未完成 Obsidian 桌面端及 Android/iOS 真机验收。

## 0.1.5 修改

0.1.5 包含以下已确认的界面与编辑改动。通过 BRAT 从旧版升级时，请选择 0.1.5；固定跟踪 0.1.4 不会自动切换到新版。旧的 0.1.4 安装包保留，不覆盖。

- 标签位于记录时间下方、正文上方。
- 电脑端共用顶部标题行，左右栏首个卡片顶部对齐。记录格子根据卡片宽度调整周数，铺满可用宽度；手机使用更大的格子。
- 电脑端点击“日记”旁的搜索按钮，打开搜索弹层。左侧为结果列表，右侧可阅读和编辑记录。
- 手机端搜索按钮延伸为搜索框，占用原记录输入框的位置。搜索期间保留未发送的草稿，收起搜索后恢复。
- 搜索结果中的菜单、编辑、删除确认和撤销保持可用。点击这些操作区域不会取消搜索。
- 电脑搜索弹层使用无边框原位编辑，工具栏从正文下方展开。标题、标签输入栏和预览点击外部收起；收起保留本次编辑内容，再次点击按钮可展开或收起。
- Esc 先收起展开的编辑控件。控件收起后，Esc 才请求结束编辑；存在未保存的修改时提供保存、放弃修改和继续编辑。保存失败时保留输入内容。
- 动画尊重系统的减少动态效果设置。

本地语法检查和 17 项自动测试通过。浏览器预览已检查桌面/手机尺寸下的搜索、编辑、保存、删除、撤销，以及真实 Esc 按键、控件收起和模拟保存失败后的输入保留。以上不代表本次已通过 Obsidian 内部或 Android/iOS 真机验收。

代码接手与验收要点见 [HANDOFF.md](HANDOFF.md)。

## 0.1.4 修改

- 修复输入文字后发送按钮文字不可见的问题，同时修复编辑时的保存按钮。
- 修复搜索框外吸顶容器的方形底色。
- 凌晨分日仍默认为 4 点。凌晨记录归入前一天文件，同时显示实际记录日期。
- 例如：11 月 2 日 02:00 写入 `日记/2026-11-01.md`，节标题为 `## 2026-11-02 02:00`，时间线显示“11月2日 02:00”。
- 旧的裸时间标题仍可读取。凌晨日期按当前分日设置推算显示，不批量重写旧文件。
- 编辑和保存新格式记录时保留完整日期；很窄的面板中允许工具栏换行。

## 排序行为

本版本保留原来的排序行为。新记录追加到文件末尾；插件按照文件顺序读取。“最新的在上面”默认开启，因此界面反向显示文件中的记录。补记不会自动按实际记录时间插回文件中间。

```sh
npm run check
npm test
```
