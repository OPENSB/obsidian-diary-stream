# 日记流

把指定日记文件夹作为数据源，在 Obsidian 中按天浏览、搜索和记录日记。作者：goo。

这是个人测试版，通过 BRAT 安装和更新。尚未提交 Obsidian 社区插件目录。

## BRAT 安装

1. 在 Obsidian 中安装并启用 BRAT。
2. 打开 BRAT 设置，选择 **Add beta plugin**。
3. 输入仓库地址：`https://github.com/OPENSB/obsidian-diary-stream`。
4. 选择版本 **0.1.4**，然后添加并启用插件。

如果库中已有手动安装的“日记流”，它与本仓库使用相同插件 ID `diary-stream`。BRAT 更新的是同一个插件；无需卸载或删除插件设置。

## 0.1.4 修改

- 修复输入文字后发送按钮文字不可见的问题，同时修复编辑时的保存按钮。
- 修复搜索框外吸顶容器的方形底色。
- 凌晨分日仍默认为 4 点。凌晨记录归入前一天文件，同时显示实际记录日期。
- 例如：11 月 2 日 02:00 写入 `日记/2026-11-01.md`，节标题为 `## 2026-11-02 02:00`，时间线显示“11月2日 02:00”。
- 旧的裸时间标题仍可读取。凌晨日期按当前分日设置推算显示，不批量重写旧文件。
- 编辑和保存新格式记录时保留完整日期；很窄的面板中允许工具栏换行。

## 排序行为

本版本保留原来的排序行为。新记录追加到文件末尾；插件按照文件顺序读取。“最新的在上面”默认开启，因此界面反向显示文件中的记录。补记不会自动按实际记录时间插回文件中间。

## 验证范围

- Obsidian 1.14.5、Baseline 主题：浅色/深色下的按钮文字、实际发送、编辑保存、重载读取。
- 390/320 像素手机模拟、320 像素窄面板：完整日期与发送按钮不溢出。
- 8 组自动回归检查：4 点边界、跨月跨年、闰日、旧格式兼容、编辑后时间保留及冲突保护。
- Android/iOS 真机尚未验证。

## 本地检查

当前仓库以可读的 `main.js` 为维护入口，未附带原始 TypeScript 工程。检查不需要安装依赖：

```sh
npm run check
npm test
```

Release 附件包含 `main.js`、`manifest.json`、`styles.css`，供 BRAT 直接下载。
